# وصلاتي

> **دفتر وصولات ومدفوعات عربي يعمل محلياً على الهاتف، حتى عند عدم توفر الإنترنت.**

«وصلاتي» هو تطبيق ويب تقدّمي موجّه لحفظ وصولات العمل وتسجيل كل دفعة وربطها بالوصل الصحيح. يحسب التطبيق المتبقي أو المبلغ المدفوع بزيادة فوراً، ويعرض الحالات بوضوح: **يتبقى دفع**، **مُسوّى**، أو **مدفوع بزيادة**. لا يحتاج التطبيق إلى حساب مستخدم أو خادم لتخزين بياناتك؛ فالسجل محفوظ في متصفح جهازك باستخدام IndexedDB، بينما يحفظ عامل الخدمة ملفات الواجهة كي يعمل التطبيق دون إنترنت بعد فتحه مرة واحدة على الأقل وهو متصل بالشبكة.[1] [2]

| --- | --- |
| رابط التطبيق | [افتح وصلاتي](https://waslatiapp-ksrdwqjn.manus.space) |
| المنصة | Android وiPhone، ويعمل كذلك في متصفحات سطح المكتب الحديثة |
| التخزين | محلي على الجهاز فقط؛ لا توجد مزامنة تلقائية أو حساب مستخدم |
| النسخ الاحتياطي | تصدير واستيراد ملف JSON من تبويب **الحماية** |
| الاتصال بالإنترنت | مطلوب في الفتح الأول والتثبيت؛ ثم يعمل السجل وواجهة التطبيق دون اتصال |

## تثبيت التطبيق على Android

افتح رابط التطبيق في **Google Chrome** على هاتف Android. من قائمة النقاط الثلاث بجوار شريط العنوان، اختر **تثبيت وإنشاء اختصار** ثم **تثبيت**، واتبع رسالة التأكيد التي تظهر على الشاشة. يضيف Chrome أيقونة «وصلاتي» إلى شاشة الهاتف أو قائمة التطبيقات، ويمكنك بعدها فتح التطبيق من الأيقونة كما تفتح أي تطبيق.[3]

> بعد التثبيت، افتح «وصلاتي» مرة واحدة مع وجود إنترنت لكي تُحفظ ملفات الواجهة. بعد ذلك تستطيع إضافة الوصولات والدفعات والبحث في السجل دون اتصال.

## تثبيت التطبيق على iPhone

افتح الرابط في **Safari** على iPhone، ثم اضغط زر المشاركة. مرر القائمة واختر **إضافة إلى الشاشة الرئيسية**، فعّل خيار **فتح كتطبيق ويب** إن ظهر، ثم اضغط **إضافة**. ستظهر أيقونة «وصلاتي» على الشاشة الرئيسية وتفتح في نافذة مستقلة تشبه التطبيق.[4]

إذا لم يظهر خيار «إضافة إلى الشاشة الرئيسية»، مرر إلى نهاية قائمة المشاركة، اختر **تعديل الإجراءات** ثم أضف الخيار إلى قائمة المشاركة.[4]

## أول استخدام آمن

ابدأ بإضافة الوصل من زر **+** في أسفل الشاشة، واكتب اسم الوصل والجهة والمبلغ والعملة. افتح أي وصل لاحقاً واختر **تسجيل دفعة**؛ سيحسب التطبيق الفرق ويعرض الحالة مباشرة. عند نقل الهاتف أو قبل مسح بيانات المتصفح، افتح تبويب **الحماية** ثم اختر **تنزيل نسخة احتياطية**. احتفظ بملف JSON في مكان آمن، وبعد فتح التطبيق على الهاتف الجديد اختر **استعادة نسخة احتياطية** وحدد الملف نفسه.

| حالة تحتاج انتباهاً | الإجراء الصحيح |
| --- | --- |
| استبدلت هاتفك أو متصفحك | صدّر نسخة JSON من الهاتف القديم ثم استوردها في الجهاز الجديد. |
| مسحت بيانات المتصفح أو استخدمت التصفح الخاص | قد يُحذف السجل المحلي؛ استعد آخر نسخة JSON محفوظة. |
| لن تفتح التطبيق دون إنترنت للمرة الأولى | اتصل بالإنترنت، افتح التطبيق مرة واحدة، ثم أعد المحاولة. |
| تريد نقل البيانات إلى شخص آخر | أرسل له ملف JSON فقط إذا كان من المناسب أن يطلع على وصولاتك؛ فالملف يحتوي بيانات السجل. |

## التشغيل من المصدر للمطورين

يتطلب التشغيل المحلي **Node.js 22+** و**pnpm**. بعد استنساخ المستودع، ثبت الاعتمادات ثم شغل خادم التطوير:

```bash
pnpm install
pnpm dev
```

لإنشاء نسخة إنتاجية قابلة للنشر:

```bash
pnpm check
pnpm build
```

يُنشأ تطبيق العميل من React وVite داخل `client/`. توجد قاعدة بيانات الوصولات في `client/src/lib/receipt-storage.ts`، وملف التشغيل دون اتصال في `client/public/sw.js`، وبيان تطبيق الهاتف في `client/public/manifest.webmanifest`.

## حدود الخصوصية والتخزين

تظل البيانات على نفس **النطاق والمتصفح والجهاز**؛ لا يمكن لجهاز آخر قراءتها تلقائياً. تطلب الواجهة تخزيناً دائماً من المتصفح عند الإمكان لتقليل احتمال إخلاء البيانات تحت ضغط مساحة التخزين، لكن النسخة الاحتياطية تبقى وسيلة الحماية الأساسية لأن المستخدم أو المتصفح يمكنه حذف بيانات الموقع.[1] [5]
