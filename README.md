# وصلاتي — تطبيق وصولات محلي للهاتف

> **تطبيق Android محلي لتصوير وصولات العمل، حفظ مبلغ كل وصل، وإتمام دفعه دون الحاجة إلى موقع أو رابط تشغيل أو خادم.**

«وصلاتي» يحفظ كل وصل وصورته ودفعاته في مساحة التطبيق على الهاتف. لا يوجد تسجيل دخول، ولا خادم لبياناتك، ولا مزامنة تلقائية. تعمل إضافة الوصولات، رؤية صورها، البحث، احتساب المتبقي أو الزيادة، وإتمام الدفع من الجهاز نفسه حتى عندما لا تتوفر شبكة إنترنت.

| الميزة | ما تفعله محلياً على الهاتف |
| --- | --- |
| تصوير الوصل | يفتح الكاميرا أو معرض الصور لربط صورة بالوصل. |
| أقل إدخال يدوي | يكفي إدخال **المبلغ**؛ العنوان القصير اختياري. |
| إتمام الدفع | زر **إتمام الدفع** يسجل كامل المتبقي ويغيّر الحالة إلى مُسوّى. |
| دفعة جزئية | يسجل مبلغاً جزئياً ويُبقي المتبقي ظاهراً. |
| حفظ خاص | صور الوصولات والسجل في ذاكرة التطبيق على الهاتف، لا في خادم. |
| نسخ احتياطي | تصدير واستيراد ملف JSON من تبويب الحماية عند تغيير الجهاز. |

## تنزيل التطبيق على Android

لا تحتاج إلى فتح موقع التطبيق. ينشئ هذا المستودع ملف APK تلقائياً في GitHub بعد كل تحديث. انتقل إلى تبويب **Actions** في المستودع، وافتح آخر تشغيل باسم **بناء APK محلي لوصلاتي**، ثم نزّل `waslati-local-android-apk` من قسم **Artifacts**. بعد فك ضغط الملف، انقل `app-debug.apk` إلى هاتفك وثبته من مدير الملفات.

> ملف APK التجريبي مخصص للاستخدام الشخصي. عند فتحه لأول مرة قد يطلب Android السماح بالتثبيت من المصدر الذي نقلت منه الملف.

اقرأ الخطوات التفصيلية في [دليل التثبيت المحلي على Android](docs/LOCAL_ANDROID.md).

## استخدام سريع

افتح «وصلاتي» من أيقونته على الهاتف واضغط زر **+**. اختر **التقط صورة للوصل**، ثم أدخل مقدار الوصل والعملة واضغط **حفظ الوصل**. افتح الوصل لاحقاً؛ ستظهر الصورة والمبلغ المتبقي. استخدم **إتمام الدفع** لتسجيل المبلغ المتبقي كاملاً أو **دفعة جزئية** إذا دفعت جزءاً منه فقط.

## الخصوصية والنسخ الاحتياطي

يعمل التطبيق محلياً ولا يعتمد على موقع Manus أو رابط تشغيل بعد التثبيت. تبقى الصور والسجلات في بيانات التطبيق على الهاتف، ولهذا ينبغي تنزيل نسخة احتياطية من تبويب **الحماية** قبل حذف التطبيق أو نقل هاتفك. ملف النسخة الاحتياطية يحتوي وصولاتك ودفعاتك وصورها المصغرة، لذلك احتفظ به في مكان خاص.

## للمطورين

يتطلب التعديل المحلي **Node.js 22+** و**pnpm**. ينفّذ الأمر التالي بناء واجهة التطبيق ونسخها داخل مشروع Android:

```bash
pnpm install
pnpm cap:sync
```

أما GitHub Actions فينشئ ملف APK تلقائياً على كل دفع إلى الفرع `main`، أو عند تشغيل سير العمل يدوياً. يوجد تعريف الغلاف المحلي في `capacitor.config.ts`، ومشروع Android في `android/`، وسير عمل البناء في `.github/workflows/android-apk.yml`.
